# 河北病院 TOPページ リニューアル

医療法人 河北会 河北病院（大阪府寝屋川市）の公式サイト TOPページリニューアル案。

## 概要

| 項目 | 内容 |
|---|---|
| 対象 | http://www.kahoku.or.jp/ |
| 技術 | HTML / Tailwind CSS / JavaScript |
| 対応デバイス | PC / タブレット / スマートフォン |

## セクション構成

1. ヘッダー（ハンバーガーメニュー・文字サイズ切替）
2. ヒーロー（キャッチコピー・病床数・電話番号 CTA）
3. お知らせ・行事案内
4. 病院について（基本理念・病床数統計）
5. 診療科のご紹介（7科）
6. 入院・外来のご案内（医療療養病棟 / 一般病棟）
7. 在宅サービス（通所リハビリ・訪問看護 等）
8. 関連施設（老人ホーム・介護スクール 等）
9. アクセス（四条畷駅 徒歩10分）
10. フッター
